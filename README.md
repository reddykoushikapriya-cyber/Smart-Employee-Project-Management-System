Smart Employee & Project Management System

A full-stack Employee & Project Management System built with React.js, Spring Boot, and MySQL. This application helps organizations efficiently manage employees, projects, and tasks through secure role-based authentication and an intuitive dashboard.

🚀 Features

🔐 Admin & Employee Role-Based Authentication

👥 Employee Management (Add, Edit, Delete, Search)

📋 Project Management

✅ Task Assignment & Progress Tracking

📊 Admin & Employee Dashboards

🔍 Search with Pagination

📅 Project Deadlines & Priorities

📈 Task Status Management

📱 Responsive Material UI Design

🌙 Dark Mode Support

🔄 RESTful APIs using Spring Boot
